# Site Wbr Criativa

## Antes de publicar
1. Abra `index.html` e troque `const WHATSAPP = "5511900000000"` pelo número real (55 + DDD + número, só dígitos).
2. Teste no navegador: F12 → Ctrl+Shift+M (modo celular).

## Publicar no GitHub Pages
1. Crie uma conta em github.com e clique em **New repository** (ex.: `wbr-criativa`, público).
2. **Add file → Upload files** e arraste `index.html`, `README.md` e a pasta `img`.
3. Clique em **Commit changes**.
4. Vá em **Settings → Pages**, em *Branch* escolha `main` / `(root)` e salve.
5. Em 1–2 minutos o site estará em `https://SEU-USUARIO.github.io/wbr-criativa/`.

## Trocar fotos
Substitua os arquivos da pasta `img/` mantendo os mesmos nomes (de preferência quadrados, até ~900px).
